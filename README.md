# ZenDiary 2.0

面向学生的“捕捉 → 整理 → 行动”工作台：把随手输入、课程时间、作业截止、可选的计划排期和提醒放进同一套工作流。待办本身就是完整状态，不需要排期；只有当你想预留具体执行时间时，才把它排进日程。

今天页以“该做什么”为中心，顶部会根据课程重复安排和显式排期提示“当前安排 / 接下来”，不要求填写预计用时，也不会替你生成学习时间块。普通待办不填关注日就从今天持续显示；Quiz 等限时任务填写开放和截止时间，开放后一直保留；准备型作业必须明确选择开始关注日，到了日期后每天保留到完成。事项未完成不会被复制到下一天，截止后会进入“已截止，待处理”。电脑与 Android 本轮各自使用本地数据，跨设备请通过设置中的 JSON 备份手动迁移。

## 主要入口

- **今天**：顶部“当前安排 / 接下来”汇总当天课程重复安排和显式排期，当前进行中的事项与同刻安排会并列显示；安排已过但尚未完成的排期待办会单独列出，可完成、调整时间或暂不安排；没有显式排期的浮动待办不会被自动安排。持续待办、已截止待处理和待补充事项保留在对应区域，可完成、撤销或打开详情；计划块若会晚于截止会显示风险提示；“今日提醒”默认折叠展示，独立提醒不计入今日负荷。
- **计划**：日 / 周 / 月视图，事件拖拽、可选的待办排期、截止日期和冲突提示。已经排进日程的待办（包括低优先级）都会在周计划中保留；其余待办完整保留在“待办池”，不会因为没有排期而被视为未整理。
- **收件箱**：唯一捕捉入口；AI 可将原文整理为事件、待办或笔记，失败时保留原文。未配置 AI 时，明确日期/钟点、中文数字时间、课程时间范围、常见地点和“每天/每周/每月”习惯仍可用本地规则整理；“晚上/稍后”这类模糊时段只保留为待办，不会擅自猜时间。只说“提醒我做某事”但没有具体时间时，会保留待确认卡，先安排计划时间再启用提醒。
- **笔记**：长期记录和 Markdown 编辑器。

桌面支持 `Alt + Space` 快速捕捉、`Alt + D` 打开计划、`Ctrl + F` 全局搜索。关闭窗口会留在托盘；便携版由进程在托盘中每 30 秒检查一次提醒，也支持从课程、待办或独立提醒详情使用“稍后 15 分钟”临时提醒。设置中可开启“登录 Windows 后启动到托盘”，这样重启后仍会检查提醒；选择“退出”后不会继续运行提醒。

## Windows 便携版

构建产物位于：

`build/windows/x64/runner/Release/`

请保留整个 `Release` 文件夹后运行 `zendiary.exe`，不要只复制 exe 文件。新版使用 v2 数据空间，不会自动导入或删除旧数据；需要迁移时可在设置中预览并导入 ZenDiary 备份。
